🚀 Fonctionnalités
📝 Gestion de notes
Créer et modifier des notes facilement :
titre personnalisé
contenu structuré
édition rapide
sauvegarde automatique
couleurs personnalisées
Les notes peuvent être modifiées, archivées ou exportées.
📂 Organisation avancée
Pour garder une structure claire :
notes actives
notes archivées
notes du jour
tri et filtrage
Cela permet de gérer facilement de nombreux contenus.
📁 Espaces de travail
L'application supporte plusieurs espaces :
👤 Personnel
Vos notes privées.
📁 Local
Espaces stockés uniquement dans votre navigateur.
👥 Partagé
Espaces synchronisés permettant la collaboration.
🔄 Synchronisation Cloud
Les notes peuvent être synchronisées via Firebase pour :
sauvegarder les données
accéder aux notes depuis plusieurs appareils
partager un espace de travail
💾 Stockage local
Les données sont également stockées dans :
LocalStorage du navigateur
Avantages :
accès hors ligne
chargement rapide
aucune dépendance serveur obligatoire
📤 Import / Export
Vous pouvez sauvegarder vos notes avec :
export JSON
import de sauvegardes
migration de données
Pratique pour :
sauvegarder
transférer ses notes
partager une base de données
📱 Application installable (PWA)
